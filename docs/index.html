quoll

A Raft-replicated key-value store built to understand how systems like etcd and Consul actually work — by building one and breaking it on purpose.

Go 1.25 Raft consensus Serf gossip gRPC Prometheus OpenTelemetry Kubernetes / Helm
▶ Interactive Architecture ↗ GitHub Repository

What's inside

Custom WAL

Binary format, CRC32 per record, segment rotation, crash recovery that stops at the first corrupt tail.

Raft consensus

hashicorp/raft, BoltDB stores, file snapshots. Quorum commit before ack. Leadership transfer on graceful shutdown.

Serf gossip

Membership and failure detection decoupled from consensus. A coordinator translates events into ring and voter changes.

Consistent hashing

Virtual nodes, server-side forwarding. A request landing on the wrong node still succeeds.

Distributed locks

TTLs + monotonic fencing tokens in the Raft log. Lock state survives leader failover.

Observability

RED metrics, OTel spans, logs by trace_id. Health + metrics on a separate HTTP port.

Smart client

Ring-aware routing, exponential backoff with full jitter, per-node circuit breaker.

Kubernetes-ready

Helm chart, StatefulSet, PodDisruptionBudget, NetworkPolicy, readiness probes, distroless image.

Quick start

SHELL
# build
make build

# three-node cluster on localhost
make run-node1   # terminal 1
make run-node2   # terminal 2
make run-node3   # terminal 3

# observability stack + sustained load
make obs-up       # Grafana :3000 · Prometheus :9091 · Jaeger :16686
make stress-live  # then kill the leader and watch the dashboard

# or run the full cluster in Docker
docker compose -f docker-compose.cluster.yaml up --build
